# 终端智能体（Agent）使用说明

本文说明 Web 端 AI 智能体的能力、权限模型与安全边界。

## 能力总览

- **两种工具通道**：
  - `run_command`：在当前 SSH 会话里执行 shell 命令（原有能力，走风险审批）。
  - 结构化文件工具（原生 tool calling）：`list_dir` / `read_file` / `search_files` / `write_file`，
    由服务端在路径沙箱内执行（见下文「沙箱与限额」），`write_file` 支持 `dryRun` 只返回 diff 预览。
- **上下文管理**：每轮拼给模型的历史消息有字符预算（设置页可调，默认 120000），
  超出的旧消息自动折叠为摘要；语义摘要触发阈值沿用原设置。
- **会话持久化**：对话消息按 `clientId + connectionId` 存在服务端
  （`DATA_DIR/agent-conversations.json`，单会话上限 500 条）；页面刷新后自动恢复上下文，
  每个连接只恢复一次，「新对话」不会被旧上下文污染。
- **附件**：支持 png/jpeg/webp/gif/pdf/text，单个 ≤10 MiB、≤8 个、24h 过期自动清理；
  转成多模态消息发给模型（OpenAI `image_url` / Anthropic `image`），不支持的类型不静默丢弃。

## 权限模式（设置页 → Agent）

| 模式 | 行为 |
| --- | --- |
| 询问后执行（默认） | 高/中风险命令执行前询问，低风险自动 |
| 自动执行低中风险 | 低/中风险自动，高危仍询问 |
| 全自动 | 全部自动（高危也自动，慎用） |
| 只读模式 | 非只读命令一律不执行，原因回给模型换方案 |

旧版三个开关（审批高危/中风险、只读）仍然兼容：未设置权限模式时按旧开关生效。

## 审计

- 每个连接保留最近 200 条结构化工具调用审计（时间、工具、路径、是否写操作）。
- 查看入口：Agent 面板状态条上的「卷轴」按钮；服务端只读接口
  `GET /api/ssh/:id/agent/audit`。

## 沙箱与限额（结构化工具）

- 路径沙箱：默认根为会话家目录（`sftp.realpath('.')`），`..` 逃逸、NUL 一律拒绝；
  每个操作路径还会做 **realpath 符号链接边界检查**——跟随链接后的真实路径越出沙箱即拒绝
  （含「穿过指向沙箱外的链接父目录创建新文件」），搜索不递归、不读取符号链接。
- 限额：读 1 MiB、列 500 项、搜 100 条 / 4 层深 / 单文件 64 KiB。
- 每次调用都会写入审计记录。

## 外部智能体（ACP）

- 位置：设置页 → Agent → 「外部智能体 (ACP)」。
- **默认关闭**，需显式打开开关；配置本机支持 ACP 协议的 CLI 智能体
  （名称 + 可执行命令 + 参数），并提供握手测试。
- 安全边界：
  - 子进程环境变量走白名单（`PATH`/`HOME`/`LANG` 等），**剥离 `SSH_AUTH_SOCK`、
    `OPENAI_API_KEY` 等敏感变量**；
  - 外部智能体的任何权限请求（`session/request_permission`）一律拒绝，
    它自己的「总是允许 / 绕过」选项不生效；
  - 配置存在 `DATA_DIR/agent-external-agents.json`（最多 10 个）。
- 一次性委托接口：`POST /api/agent/acp/:name/prompt`（等待回合结束，返回更新流）。

## 已知边界（如实说明）

- Anthropic 适配器与附件多模态为单测级验证，未连真实账号端到端跑过。
- ACP 目前只有配置管理 + 握手测试 + 一次性委托接口，没有独立的对话 UI 入口。
